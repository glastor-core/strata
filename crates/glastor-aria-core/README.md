# glastor-aria-core

Headless WAI-ARIA 1.2 accessibility primitives and deterministic state machines for Rust web frameworks.

## Features
- **Deterministic FSMs**: Event-driven state machines with zero framework coupling.
- **`FocusTrap`**: Bound cycling focus trapping with boundary sentinels and restoration.
- **`DismissableLayer`**: Stacked layer management for Escape and outside click handling.
- **`RovingTabindex`**: WAI-ARIA compliant keyboard navigation for composite widgets.
- **Type-Safe ARIA**: Strict attributes conforming to WAI-ARIA 1.2 specifications.
